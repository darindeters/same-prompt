# Same Prompt

Four AI coding agents get the exact same prompt and build a visual simulation as one HTML file. Every page here is the file the agent wrote, unedited. Open them and judge for yourself.

From the Tech with Darin Shorts series: https://www.youtube.com/@techwithdarin

## The rules

- Same prompt text, word for word, for every agent.
- An empty folder, medium effort set explicitly, no web access, a 30-minute cap.
- Each agent runs in a sandbox that can only write to its own folder.
- Build time is wall-clock time from launch to exit.
- Videos are recorded in the same headless Chrome on a virtual clock: every page gets the same 26 seconds of its own time, so a slow page never drops frames.

`runs.json` has the model, effort, CLI version, start time and build time for every run.

> Build a black hole with a glowing accretion disk that bends the light of the stars behind it, as one self-contained file named index.html in this folder. It must start animating as soon as the page loads, with no clicks or key presses, fill the whole browser window, and look its best in a square 1080 by 1080 window.
